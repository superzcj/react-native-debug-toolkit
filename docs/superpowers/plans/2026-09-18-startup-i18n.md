# Startup Internationalization Implementation Plan

> **For agentic workers:** Execute bounded tasks with subagent-driven-development, within the authoritative FlowPilot execution plan. Return after your assigned task.

**Goal:** Configure English or Simplified Chinese once at startup for the phone panel and Web Console.

**Architecture:** Shared JSON dictionaries provide common and RN messages; Web Console adds its own namespaced messages. RN resolves locale during initialization and reads it from a plain module; the browser resolves locale once from injected Hub configuration. No reactive language subsystem is needed.

**Tech Stack:** Existing TypeScript, React Native, Node.js, JSON, Jest; no new runtime dependency.

**Spec:** `docs/superpowers/specs/2026-09-18-startup-i18n.md`

## Global Constraints

- Languages: `auto | en | zh-CN`; default `auto`.
- Locale is fixed for an initialized toolkit/page; reload after configuration changes.
- No runtime setter, subscription, language button, locale persistence or foreground listener.
- Do not translate raw data, stable identifiers or caller-supplied labels/copy.
- No new runtime dependencies. Keep React >=18 and RN >=0.72 support.
- Work on `codex/startup-chinese-locale`; do not publish or commit generated build output.

**Ownership:** `src/`, native bridge files only if necessary; parent owns documentation.

**Files:** Create `src/i18n/index.ts`, `src/i18n/locales/en.json`, `src/i18n/locales/zh-CN.json`, `src/__tests__/utils/i18n.test.ts`. Update `src/core/initialize.ts`, `src/ui/DebugView.tsx`, `src/index.ts`, panel/shared UI and feature presentation files, and affected behavior tests.

**Interfaces:** Export `DebugLocale = 'en' | 'zh-CN'`, `DebugLocaleOption = DebugLocale | 'auto'`; internal `configureLocale(option?: DebugLocaleOption): void`, `getLocale(): DebugLocale`, `t(key, params?): string`. JSON uses flat semantic keys, including `common.copy`, `common.back`, `common.all`, `common.search`; web may consume these resources read-only. Locale is configured before feature initialization. Labels evaluated before initialization must resolve at display time without a subscription.
