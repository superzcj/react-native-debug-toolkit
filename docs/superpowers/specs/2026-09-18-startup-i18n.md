# Startup language configuration

## Approved scope

Add English and Simplified Chinese to the React Native debug panel and Web Console. Language is configured once at initialization; changing configuration requires reloading. Do not add a language store subscription, foreground listener, runtime setter, switcher UI, persistence, or external internationalization dependency.

- `DebugView.locale` and `InitializeOptions.locale`: `auto | en | zh-CN`; default `auto`.
- Auto detection recognizes Simplified Chinese; Traditional Chinese and unsupported locales fall back to English. Detection failure also falls back to English.
- Hub accepts startup language configuration. In auto mode each browser resolves its own language on page load. Phone and browser language choices are independent.
- Translate built-in titles, short rail labels, summaries, empty states, buttons, prompts, accessibility labels and relative dates. Keep technical product names, raw log data, protocol fields, feature identifiers, environment names and caller-provided copy unchanged.
- Use shared JSON translation resources, namespaced web additions, lightweight interpolation and English fallback. No remote dictionaries or caller dictionary override API.
- Preserve existing rendering and capture architecture. Reading translations must work when feature objects are created before toolkit initialization.

## Validation

Verify explicit/automatic language selection, fallback, dictionary and interpolation parity, RN initialization, custom-copy precedence, browser instance isolation and HTML escaping. Run type checking, relevant test suites, lint, build and package inspection. Device layout verification is reported separately from automated checks.
